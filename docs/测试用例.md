# 问卷系统测试用例文档

> 配套文档：大作业一第一阶段 / 项目根目录 `survey_system/`
> 测试方式：手工测试 + API 测试（混合）
> 测试数据基础：本测试以手工创建的问卷"2"（含 4 道题、匿名收集、启用条件跳转）为输入，通过真实浏览器操作和后端 API 协同验证。

---

## 0. 测试环境与前置条件

| 项目 | 值 |
|------|----|
| 后端 | FastAPI，地址 `http://localhost:8000` |
| 前端 | 静态 HTML，地址 `http://localhost:8000`（与后端同源） |
| 数据库 | MongoDB ≥ 6.0，本地实例 |
| 浏览器 | Chrome / Edge / Safari 最新版 |
| 测试账号 | `creator`（问卷创建者）、`cal`、`pyf`（问卷填写者） |

**前置步骤**
1. MongoDB 已启动：`brew services start mongodb-community`
2. 后端已启动：`uvicorn app.main:app --reload --port 8000`
3. 前端可访问：`http://localhost:8000`
4. 通过 `frontend/index.html` 注册并登录创建者账号 `creator`
5. 通过 `frontend/fill.html?token=<token>` 验证两位填写者账号（`cal`、`pyf`）可登录

> 用例标题前的 4 个字段（测试步骤 / 输入 / 输出 / 结果）为题目硬性要求，下文每条用例均按此格式呈现。

### TC-CREATE-01 创建空白问卷并发布

| 字段 | 内容 |
|------|------|
| **测试步骤** | 1. 登录 `creator` 账号<br>2. 进入"我的问卷"页面，点击"创建新问卷"<br>3. 在标题框输入 `2`，勾选"允许匿名填写"，保存<br>4. 点击问卷卡片的"发布"按钮<br>5. 复制生成的 Token 链接 |
| **输入** | 标题：`2`；`allow_anonymous=true` |
| **输出** | 1. 问卷列表新增一条记录，状态 = `draft`<br>2. 发布成功后状态变为 `published`，生成 7 位 Token（如 `EO3ziWN`）<br>3. 链接形如 `http://localhost:8000/fill.html?token=EO3ziWN` |
| **结果** | ✅ 通过（实测 `POST /api/surveys` 返回 200，`POST /api/surveys/{id}/publish` 返回 200，Token 链接可被打开） |

### TC-QADD-01 添加文本题（带必答 + 跳转）

| 字段 | 内容 |
|------|------|
| **测试步骤** | 1. 在问卷"2"的题目编辑页填写新增题目表单<br>2. 题干 = `用户名`，题型 = 文本，必答 = 是，跳转 = 下一题<br>3. 提交新增 |

| **输出** | 1. 题目列表新增一项，order=1<br>2. 后端返回完整题目对象（含 `_id`、`survey_id`、`order`） |

### TC-QADD-02 添加单选题（按选项跳转）

| 字段 | 内容 |
|------|------|
| **测试步骤** | 1. 继续在问卷"2"添加题目<br>2. 题干 = `今天周几`，题型 = 单选，选项 = 周一/周二/周三，必答 = 是，跳转 = 按选项跳转<br>3. 选项"周一"→ 题号 3；选项"周二"→ 题号 4；选项"周三"→ end |
| **输入** | `{"title":"今天周几","type":"single","options":["周一","周二","周三"],"required":true,"next_rule":{"mode":"by_option","fallback":"end","branches":[{"when":"周一","goto":3},{"when":"周二","goto":4},{"when":"周三","goto":0}]}}` |
| **输出** | 1. 题目 order=2，next_rule 字段被持久化<br>2. 数据库 `questions` 集合新增一条完整文档<br>3. 前端题目列表中显示跳转规则摘要 |
| **结果** | ✅ 通过（goto=0 在发布前被识别为"end"；前向引用 goto=3、goto=4 在创建时允许，符合设计文档语义） |
